# Задание 1. Анализ и планирование

Проект warmhouse позволяет управлять отоплением и а так же мониторить температуру в умном доме.

**Управление отоплением:**

- Пользователи могут:
    - Смотреть/изменять настройки системы
    - Включить/выключить отопление
    - Устанавливать температуру 

**Мониторинг температуры:**

- Мониторинг температуры с датчиков системы


### 2. Анализ архитектуры монолитного приложения

Язык программирования: Java

База данных: PostgreSQL

Архитектура: Монолитная, все компоненты системы (обработка запросов, бизнес-логика, работа с данными) находятся в рамках одного приложения.

Взаимодействие: Синхронное, запросы обрабатываются последовательно.

Масштабируемость: Ограничена, так как монолит сложно масштабировать по частям.

Развёртывание: Требует остановки всего приложения.

### 3. Определение доменов и границы контекстов

**В системе можно выделить следующие домены:**

1. Аутентификация и авторизация
2. Управление системой отопления
3. Мониторинг системы

### **4. Проблемы монолитного решения**

1. Сложно масштабирования
2. По мере увеличения кодовой базы снижается скорость и качество разработки
3. Низкая скорость доставки на продакшн
4. Синхронные взаимодействия могут создавать узкие места и негативно влиять на производительность
5. Ограниченная отказоустойчивость — при наличии ошибки в одном из компонентов вся система будет не работоспособна.

# Задание 2. Проектирование микросервисной архитектуры

**Выделим новые домены:**

1. Домен управления аккаунтом и авторизации — User Service
    - Регистрация пользователей
    - Управление сессиями
    - Аутентификация и авторизация пользователя
    - Управление данными аккаунта пользователя

2. Домен управления домами — Home Service
    - Добавление и удаление домов
    - Привязка устройств к домам

3. Домен управления устройствами — Device Service
    - Регистрация умных устройств в системе
    - Конфигурация умными устройствами
    - Создание пользовательских сценариев и настройки автоматизации
    - Адаптеры умных устройств

4. Сервис мониторинга — Monitoring Service
    - Сбор данных мониторинга и телеметрии, приведение их к определенному формату
